## Regenerating the approval-digest fixture

```bash
from gandiwa_api.creative.models import CreativeSession, PromptSnapshot

                        content_type="photo", creation_method="generative_ai",
                        provider_id="fal", model_id="fal-ai/flux/schnell",
                        target_width=4096, target_height=3072,
                        aspect_ratio="4:3", orientation="landscape")
material = prompt.model_dump(mode="json")
print(json.dumps(material, sort_keys=True, separators=(",", ":"))[:80], "…")
from gandiwa_api.creative.approval import current_prompt_digest
print(current_prompt_digest(CreativeSession(topic="fixture", prompt=prompt)))
PY
```

with sorted keys and compact separators; any fixture can be regenerated by
