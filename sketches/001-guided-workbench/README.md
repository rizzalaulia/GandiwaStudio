## Variant: Guided Workbench

### Design stance
A desktop workbench with a persistent five-step workflow rail; suitable when users need orientation and occasional navigation across project surfaces.

### Key choices
- Layout: sidebar + compact stepper + active task + next-action rail.
- Hierarchy: current durable action dominates; evidence details are collapsed.
- Interaction: clicking the main action advances the visible active step.
- Visual posture: dark, restrained, one lime action accent.

### Trade-offs
- Strong at: multi-project orientation, explicit process visibility, future room for files/history.
- Weak at: still carries a fair amount of chrome; less calm than the Runway.

### Best for
A working production tool where users regularly switch project, asset, or evidence history.
