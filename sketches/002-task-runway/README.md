## Variant: Task Runway

### Design stance
One-task-at-a-time workspace that removes every nonessential decision from the active path.

### Key choices
- Layout: editorial single-column task card plus a lightweight runway checklist.
- Hierarchy: one large sentence, one current durable action, one reason for the locked future.
- Interaction: completion turns the action into a completed state and shifts the user's next task.
- Visual posture: warm paper, restrained green, intentionally low cognitive load.

### Trade-offs
- Strong at: first-time users, manual review flow, reducing visual fatigue.
- Weak at: power users may need a project/file inspector elsewhere.

### Best for
Gandiwa's default guided path from master asset to approved export.
